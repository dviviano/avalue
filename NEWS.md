# avalue 0.1.0

## Initial release

- Calculates A-values from point estimates and standard errors.
- Accepts exact two-sided normal p-values when standard errors are unavailable.
- Supports a common or estimate-specific follow-up standard-error ratio `w`.
- Returns paper-style logarithmic histograms and rank-comparison plots.
- Supports exact top-q selections with deterministic tie-breaking by estimate ID.
